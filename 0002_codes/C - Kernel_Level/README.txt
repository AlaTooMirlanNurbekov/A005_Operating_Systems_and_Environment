Welcome to the C edition of this operating systems and environment. You chose the challenging path, and I respect that. Working with C is not always easy, but it is the closest you can get to how real operating systems work. 
I want you to know why we use C here:
- C is the native language of operating systems (Linux, Windows, macOS, Android kernel)
- System calls, process creation, memory management, file operations are done via C-level APIs
- C gives you direct control over memory and low-level resources
- Unlike Java or Python C does not hide the OS behind abstractions
- When you write C, you interact more closely with the OS kernel than in any other high-level language

By choosing this version, you are learning how the OS actually behaves (real system calls) understanding memory, processes, and files from a low-level perspective, preparing yourself for advanced topics like systems programming, cybersecurity, and embedded systems
This path requires effort, but it gives power and deep technical understanding that very few students achieve
